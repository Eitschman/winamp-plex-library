# Winamp Plex Library 0.3.4.1

## Changes

- Display album artwork directly beside the music fields in Plex track information (Alt+3). The image is shared with Winamp's existing album-art service; no additional Plex request is made.
- Preserve image proportions and transparency. Missing images and image-decoding errors have distinct visible states, with the music fields still available.
- Use a compact layout with borderless, selectable read-only values, an emphasized title and grouped year, track number, duration and format.
- Inherit colors and fonts from the active Media Library skin, including the artwork area. German and English follow Winamp's language pack.
- Add automated panel rendering checks for non-square images, transparency, skin colors, missing/corrupt artwork, text selection and read-only behavior. Extend package checks to validate both three-part and four-part release tags.

No playback URL, server address, Plex identifier, path or credential is supplied to the panel. Audio payloads, buffering, seeking and playlist restoration are unchanged. Foreign local files and web radios retain their native information dialogs.

## Upgrade

Close Winamp and replace `ml_plex.dll` in its actual Plugins directory beside `gen_ml.dll`. Preserve the protected settings and playlist-reference files. Windows 10/11, Winamp 5.9.2 Build 10042 x86 and the Microsoft Visual C++ v14 runtime for x86 are required. WACUP remains unverified.

Validation evidence and remaining limits are recorded in [Testing](../testing.md).
