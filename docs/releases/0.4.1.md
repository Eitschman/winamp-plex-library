# Winamp Plex Library 0.4.1

## Changes

- Rediscover the selected Plex server after connection failures, including a changed public IP on the home router. Verify HTTPS and the same server identity before authenticated access.
- Keep existing Plex playback links and playlist entries when the address changes. Local files, web radios and playlist order remain under Winamp's control.
- Share address refreshes between concurrent requests and retain cancellation and bounded retries. HTTP authentication errors remain distinct from network failures, and manually fixed Advanced connections remain fixed.
- Store the Plex account token with CurrentUser DPAPI for rediscovery. The account token is sent only to Plex services; PMS receives its resource token. No token or private server address is added to playback links or diagnostics.

## Upgrade

Exit Winamp and replace `ml_plex.dll` in the actual Plugins directory next to `gen_ml.dll`. Preserve the protected configuration, `playlist-references.dpapi` and saved playlists.

After upgrading an older profile, open Settings and choose Sign in with Plex once. Approve access in the browser, select the same server and music library, then Save. This stores the additional account token in the encrypted profile. Do not clear the playlist or re-add its registered tracks. Automatic mode is required for address rediscovery; a fixed Advanced connection intentionally stays fixed.

## Validation and limits

Synthetic tests reproduce the failure with an old address and exercise recovery to a new HTTPS address, resource-token renewal, server identity rejection, account revocation, fixed routes, legacy profiles, cancellation, concurrent failures and error cooldown. Configuration tests check encrypted account-token roundtripping and absence of its plaintext in the DPAPI file. Existing transport, playlist and lifecycle suites remain part of the release checks.

Local x86 Debug and Release each pass all 21 CTest suites, including 33 connection-recovery checks. All 13 package checks pass. The muted/minimized native Winamp test passes saved-playlist restart, prefetch/seeking and mixed Plex/local/radio transitions without changing foreign URLs or order. The normal installation and original protected profile remain unchanged. GitHub Actions repeats both builds/tests and the redacted full-history secret scan before publication.

A real router IP change has not been forced. Recovery depends on Plex advertising a reachable current address; an outage longer than buffered audio can still interrupt playback. Byte-exact continuation still requires an unchanged strong ETag and exact HTTP range/length responses. Initial seeking responses remain outside that continuation path. Existing storage, decoder and playlist-reference limits still apply. See [testing](../testing.md).
