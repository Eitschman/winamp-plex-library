# Winamp Plex Library 0.3.4

## Changes

- Open a native skinned Plex track-information dialog using Winamp's File Information command (Alt+3), including selected playlist entries.
- Display title, artist, album, album artist, genre, year, track number, duration and audio format when available. Missing values show a dash. Fields are read-only and can be selected/copied.
- Keep connection details, playback URLs, server addresses, file paths, Plex identifiers and credentials out of the information panel.
- Preserve native information dialogs for local files and web radios. Mixed selections retain their order and stop when a dialog is cancelled.
- Read optional Plex genre tags with bounded parsing and malformed-response tests.

Audio payloads, buffering, seeking, protected playlist restoration and decoder selection are unchanged. No ICY metadata is inserted into audio streams. An unbound saved Plex entry needs playback restoration before the panel can show its music fields. The panel does not edit tags or replace Winamp's album-art service.

## Upgrade

Close Winamp and replace `ml_plex.dll` in its actual Plugins directory beside `gen_ml.dll`. Preserve the existing protected settings and playlist-reference files. Windows 10/11, Winamp 5.9.2 Build 10042 x86 and the Microsoft Visual C++ v14 runtime for x86 are required. WACUP remains unverified.

Validation evidence and remaining limitations are recorded in [Testing](../testing.md).
