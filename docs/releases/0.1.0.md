# Winamp Plex Library 0.1.0

Native Plex Media Library plugin for Winamp 5.9.2 Build 10042, x86, on Windows 10/11.

## Included

- Plex browser sign-in, server and music library selection, and user-bound DPAPI storage.
- Artists, albums, tracks and audio playlists with search, sorting and Winamp playlist integration.
- Album artwork, native skin integration and language selection inherited from Winamp.
- Direct Play through a local proxy or private prepared media files, using Winamp's decoders without automatic transcoding.
- Plex playback status and personal track ratings.
- Artist and title together in Winamp's playlist and current track display, with separate metadata fields.
- Bounded, byte-exact resumption of interrupted full media responses, guarded by ETag and range validation, with retained numeric failure diagnostics.

## Installation

Download and extract `WinampPlexLibrary-0.1.0-win32.zip`. Exit Winamp and copy only `ml_plex.dll` into the Plugins directory actually used by your installation, next to `gen_ml.dll`. Microsoft Visual C++ v14 Runtime for x86 is required. The included `INSTALL.md` covers prerequisites, sign-in and removal. Keep the license notices. `SHA256SUMS.txt` contains the ZIP checksum.

## Validation and limitations

“The Puppeteer” reached its natural end at a decoder duration of 273 seconds after an actual upstream interruption and resumption. “Until Dawn” passed an additional audible natural-end test at 369 seconds. Both used the isolated copy of the target Winamp version and an existing Plex server.

Resumption requires a full GET, a known length and a strong ETag. Initial HTTP 206 seeking responses are excluded. Persistent network outages remain errors. The exact cause of the premature upstream termination remains unresolved; the observed recovery is not a general stability guarantee.

The release workflow builds Debug and Release for x86 and publishes only after CTest and package validation pass. Native evidence and unverified cases are documented in `docs/testing.md`.

WACUP has not been tested at runtime. IPv6 origins are unsupported. FLAC, OGG and ADTS-AAC require local preparation, limited to 512 MiB per file and 2 GiB overall. AAC-LC has synthetic coverage; real Plex ADTS tracks and additional AAC profiles remain unverified. Saved loopback URLs cannot be reused after restarting the plugin.
