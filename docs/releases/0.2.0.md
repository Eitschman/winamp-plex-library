# Winamp Plex Library 0.2.0

Native Plex Media Library plugin for Winamp 5.9.2 Build 10042, x86, on Windows 10/11.

## Changes

- Progressive private disk buffering separates Plex downloading from Winamp's decoder consumption. An active response starts after a bounded initial buffer; playback remains Direct Play without audio re-encoding.
- Settings → Diagnostics refreshes received/sent MiB, active streaming downloads and shared media-storage usage every second.
- Saved Winamp playlists can replay registered Plex tracks after a process restart. Exact server, track and media-part references are encrypted with CurrentUser DPAPI; current authentication and server identity are verified again before playback.
- Restored tracks retain separate title, artist, album and album-artist metadata, available artwork and Plex playback-status reporting.
- Mixed playlists retain local files and web radios in their original positions. Selecting a foreign source does not require Plex reference lookup; a damaged Plex index does not prevent that source from playing.
- Stop, playlist edits and connection changes invalidate pending restoration. A rejected duplicate prepared-file handoff preserves existing file and metadata bindings.

## Installation and upgrade

Download `WinampPlexLibrary-0.2.0-win32.zip` and verify it against `SHA256SUMS.txt`. Exit Winamp, preserve the existing DLL, and copy only `ml_plex.dll` into the Plugins directory actually used by your installation, next to `gen_ml.dll`. Keep the license notices. The Microsoft Visual C++ v14 Runtime for x86 is required. `INSTALL.md` contains setup and removal instructions.

Existing sign-in settings remain in the encrypted `connection.dpapi` file. Keep the new `playlist-references.dpapi` file in the same private settings directory when retaining saved playlists. Plex entries created before reference recording must be added again from the Plex library once, then saved again. Display titles cannot recover missing Plex identities. Playlist files do not contain Plex credentials.

## Validation and limitations

Debug and Release each pass 15 automated suites, with seven package checks. Native muted tests use a separate Winamp 5.9.2 Build 10042 copy. Real MP3, M4A, FLAC and OGG samples pass process-restart restoration; checks cover metadata, artwork bindings, Plex status and automatic advancement. Editor Play, double-click, Enter, IPC start and shuffle are exercised. An endless HTTP/ICY radio fixture verifies mixed-source transitions and saved mixed-list restart without credential headers or changes to foreign addresses. Fault checks cover Stop, concurrent edits, shutdown, a damaged index, wrong server and unknown aliases.

The buffer is checked with complete-byte comparisons, decoder backpressure, cancellation and real MP3/M4A natural endings. Persistent network failure can still interrupt playback; buffering does not guarantee recovery from every outage. A prepared-media re-download reported premature upstream EOF and refused the incomplete file. An intermittent process-handle guard failure remains documented; targeted repeats and subsequent full local/CI runs pass. See `docs/testing.md` in the repository for evidence and limits.

Restoration requires the same Windows user/profile, the selected Plex server and online access. It supports up to 10000 playlist entries, 100000 retained aliases and a 64 MiB protected registry. When Plex restoration is needed, stale owned entries are prepared before resuming. Private media storage is limited to 512 MiB per file and 2 GiB overall. This is not portable or offline playback, permanent HTTP links or next-track prefetch. Existing HTTP grant expiry remains enforced.

IPv6 origins are unsupported. WACUP, real Plex ADTS replay, additional AAC profiles, multipart replay and third-party startup/queue overrides remain unverified. Classic, Winamp Modern, Bento and Big Bento have existing skin checks; arbitrary skins and DPI settings are not covered.
