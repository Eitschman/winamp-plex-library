# Winamp Plex Library 0.3.3

## Changes

- Display diagnostic data sizes in decimal MB (1 MB = 1,000,000 bytes) instead of MiB.
- Convert both live counters and storage limits consistently. The unchanged storage limits appear as 2147.4 MB for shared media storage and 67.1 MB for next-track prefetch, with a comma in German.
- Keep byte-level transfer-failure details for troubleshooting.

## Upgrade

Close Winamp and replace `ml_plex.dll` in its actual Plugins directory beside `gen_ml.dll`. Keep existing settings and `playlist-references.dpapi`. The package targets Windows 10/11 and Winamp 5.9.2 Build 10042, x86, and requires the Microsoft Visual C++ v14 runtime for x86.

Demand-driven playlist restoration and playback behavior remain unchanged. WACUP remains unverified.

## Validation

German and English diagnostic panels were visually inspected, including their complete last line and converted limits. Automated host assertions and native settings checks cover the new units; the host regression rejects the preceding DLL's MiB display. Debug passes all 18 suites. Release passes 17 suites initially and its remaining observation suite passes a separate recheck; the initial failure reports the documented intermittent Windows IME windows. Seven packaging checks pass. No resource-leak fix is claimed. Publication requires successful GitHub Actions builds, package checks and secret scanning.
