# Winamp Plex Library 0.3.0

## Changes

- Prefetch the next owned MP3/M4A playlist entry in the background. Complete speculative files are limited to 32 MiB each, with at most the current and next file retained. Diagnostics expose cached bytes, cache hits, activity and errors.
- Add server-side genre, album-year and audio-format filters where supported by the selected library view.
- Save named library views and restore navigation, selected rows and scroll position across view changes and Winamp restarts. Preferences use the existing user-bound DPAPI configuration.
- Add a native skinned filter dialog, including German and English text inherited from Winamp, and adapt the action row to narrow library windows.
- Expand regression coverage for prefetched playback, network interruption, filter parsing, protected preferences, mixed playlists and native layout bounds.

## Upgrade

Close Winamp and replace `ml_plex.dll` in the actual Plugins directory beside `gen_ml.dll`. Keep the existing DPAPI settings and playlist-reference files. This package targets Windows 10/11 and Winamp 5.9.2 Build 10042, x86, and requires the Microsoft Visual C++ v14 runtime for x86.

## Validation and limits

Debug and Release each pass 18 automated suites locally. Muted native checks in an isolated Winamp copy cover MP3/M4A prefetch consumption and seeking, saved-playlist restart, local/radio/Plex mixtures and shuffle playback. Library filters are checked against a real Plex server. Selection and scrolling survive a process restart. The filter dialog was visually inspected in Classic, Winamp Modern, Bento and Big Bento, including German and English; narrow layouts are checked down to 420 by 330 pixels.

Prefetch follows the physical next entry only when shuffle is disabled. It does not predict queue-plugin decisions or change playlist order. Incomplete speculative downloads are never served. Prepared FLAC/OGG/AAC files retain their existing preparation path. The cache is private and temporary, not a persistent offline library; extended outages can still interrupt playback. Saved playlists still require the registered user profile and access to the selected Plex server.

WACUP, arbitrary third-party skins and other DPI settings have not been generally validated. See `docs/testing.md` for test evidence and remaining integration limits.
