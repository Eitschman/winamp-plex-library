# Winamp Plex Library 0.3.1

## Fixes

- Show the entire diagnostics text, including the final local-disconnect counter. The dialog measures wrapped text with its actual skin font and grows the content area and button position as needed.
- Vertically center search text with Winamp's native skin-engine option. The search field retains its original height, skin colors and single-line editing behavior.
- Add native regression checks for clipped diagnostic text and missing search-text alignment, with deliberately broken cases to verify both guards.

## Upgrade

Close Winamp and replace `ml_plex.dll` in the actual Plugins directory beside `gen_ml.dll`. Keep existing settings and playlist-reference files. The package targets Windows 10/11 and Winamp 5.9.2 Build 10042, x86, and requires the Microsoft Visual C++ v14 runtime for x86.

## Validation and limits

The UI corrections were visually inspected in Classic and Bento. Diagnostics were checked in German and English, including automatic refresh. Native layout checks cover 1024 by 600, 600 by 400 and 420 by 330 pixel views. Debug and Release each pass 18 automated suites for the corrected source; publication additionally requires both configurations and package validation in GitHub Actions.

Intermediate lifecycle checks observed two remaining Windows IME windows; subsequent comparison runs and the final suites pass without relaxing resource guards. No resource-leak fix is claimed. Arbitrary third-party skins, other DPI configurations and WACUP remain outside the verified coverage. See `docs/testing.md` for evidence and limitations.
