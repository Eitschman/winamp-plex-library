# Winamp Plex Library 0.4.0

## Changes

- Browse related artists, albums and tracks in selection panes modeled on Winamp's local Audio library. Artists shows artists and albums above tracks; Albums and Playlists show their selection above tracks. Tracks remains a direct track list.
- Narrow dependent lists with a single click. Use All artists or All albums to remove a selection, and double-click a track to play it. Album and playlist context actions remain available.
- Adjust pane sizes with draggable dividers or arrow keys when a divider has focus. Narrow and low windows prioritize title, artist and duration.
- Identify search scope with persistent Search artists, Search albums, Search tracks or Search playlists labels. Search is scoped to names in the current area, rather than searching every field at once.
- Reset search, artist/album/playlist selection, genre/year/codec filters and page offsets together. Reset has a text-only caption; Escape in the search field performs the same action. Keep the selected music library and navigation area.
- Start area visits without implicit search/filter restrictions. Named saved views still restore restrictions only when explicitly applied. The unfiltered Tracks area retains selection, page and scroll restoration.
- Align library labels and values, match Settings/Reset button widths, and move cache clearing to Settings. Controls inherit Winamp's active skin and German/English language.
- Show every table's page range as 1-250 of 306, localized as 1-250 von 306. Center it horizontally and vertically between page arrows, or right-align it beneath the table when no page buttons are needed.
- Load bounded dependent pages asynchronously, cancel superseded requests and reuse cached pages. Searches and area changes do not block the Winamp UI.

Playback transport, progressive buffering, prefetch, protected playlist restoration and audio decoding are unchanged. Available album artwork remains visible beside tracks and in the skinned Plex track-information panel. No connection, URL, path or credential fields are added to the interface.

## Upgrade

Close Winamp and replace only `ml_plex.dll` in the actual Plugins directory beside `gen_ml.dll`. Preserve the existing DLL and keep the DPAPI-protected connection and playlist-reference files. Existing named views remain available; implicit search/filter constraints and old drill-down positions are intentionally not restored. No new sign-in is required solely for the upgrade.

Windows 10/11, Winamp 5.9.2 Build 10042 x86 and the Microsoft Visual C++ v14 runtime for x86 are required. The ZIP contains installation instructions and license notices; SHA256SUMS.txt provides its checksum.

## Validation and limits

Native browser checks cover related selection, album identity, sorting, selector paging, full reset, pending-search cancellation, area isolation, named views and unfiltered Tracks positions. Tests include invalid range/alignment counterchecks and rapid searches. Classic, Winamp Modern, Bento and Big Bento have been inspected; footer and header refinements have additional Classic/Bento checks at four window sizes. See [Testing](../testing.md) for build, automated test and CI evidence.

Versioned x86 Debug and Release builds each pass all 20 automated suites, and all 13 package checks pass. The local package reports DLL version 0.4.0 and contains only the allowlisted DLL, installation instructions and license files. Redacted Git-history and package scans report no secret findings. GitHub Actions repeats the history scan, both builds/tests and package validation before publication.

A real second music library, further third-party skins, additional DPI settings and WACUP remain unverified. Search intentionally follows the current area. Known playback and storage limits in the [README](../../README.md#security-and-limitations) still apply.
