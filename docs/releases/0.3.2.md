# Winamp Plex Library 0.3.2

## Changes

- Restore the requested Plex playlist entry first, then prepare at most one predicted successor. Unrelated stale or unavailable entries no longer block the requested track.
- Add FLAC, OGG and ADTS-AAC selections as protected deferred aliases without downloading the entire selection. Complete the individual file before opening its decoder.
- Release prepared targets outside current playback and its predicted successor. Returning to an evicted entry resolves and downloads it again, within the existing shared storage limits.
- Replace resolved filenames in place to preserve Winamp's shuffle table. Actual navigation and automatic advancement use Winamp's native selection; predictions are only used for prefetch.
- Give playback requests and library handoffs priority over speculative work. Independent cancellation prevents prefetch from discarding queued library additions or interrupting current audio.
- Keep local files and web radios in mixed playlists independent of Plex authentication and reference-store failures.

## Upgrade

Close Winamp and replace `ml_plex.dll` in the actual Plugins directory beside `gen_ml.dll`. Keep existing settings and `playlist-references.dpapi` so saved playlists retain their protected Plex identity. The package targets Windows 10/11 and Winamp 5.9.2 Build 10042, x86, and requires the Microsoft Visual C++ v14 runtime for x86.

Developers with existing SDK headers should run `scripts/Fetch-WinampSdk.ps1 -PlaybackOnly` to obtain the additional checksum-pinned original Nullsoft IPC header.

## Validation and limits

Muted native tests cover a 204-entry mixed playlist, requested-entry preparation, eviction and return, real FLAC/OGG playback, natural advancement, cancellation and shutdown during an active FLAC download. MP3/M4A tests cover 18 simulated shuffle EOF events across repeated cycles, manual repeat, Stop After Current, editor Play/double-click/Enter, process-restart restoration, metadata/artwork/timeline and HTTP/ICY radio. Two library additions during local-format prefetch preserve current audio. The user also reports successful playback with the installed development DLL.

Version 0.3.2 passes all 18 automated suites in local Debug and Release builds, plus seven package checks. Intermediate feature-validation runs observed the documented intermittent USER-object imbalance with Windows IME windows; no resource-leak fix or weakened assertion is claimed. Publication also requires the GitHub Actions builds, package checks and secret scan to succeed. See `docs/testing.md` for individual evidence and limitations.

Limits remain 10000 playlist entries during restoration, 512 MiB per prepared file and 2 GiB shared media storage. An individual local-format download still completes before playback. One extended FLAC/OGG shuffle run encountered premature upstream EOF (Windows 38); the incomplete file was rejected. No extended passing result is claimed for that run. Real Plex ADTS replay, arbitrary queue-override plugins and WACUP remain unverified. This is a session cache, not portable or offline playlist storage.
